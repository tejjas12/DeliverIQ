02 / PROBLEM STATEMENT

Why Did We Build DeliverIQ?

Food delivery time can vary depending on multiple operational factors such as weather conditions, road traffic, delivery distance, vehicle condition, order type and delivery person characteristics.

Understanding these factors through raw data alone can be difficult. DeliverIQ addresses this challenge by applying data processing, exploratory analysis and regression-based machine learning to study delivery patterns and estimate delivery duration.

Dataset Acquisition from Kaggle

We started by obtaining the Zomato Food Delivery Dataset from Kaggle. The original dataset contained 45,584 records and 20 columns describing delivery operations and order conditions.

THE DELIVERIQ JOURNEY

Turning Data Into Intelligent Decisions.

DeliverIQ demonstrates an end-to-end data science workflow: collecting raw data, assessing data quality, cleaning and transforming information, integrating reference datasets, discovering patterns through EDA, preparing machine learning features, training and evaluating regression models, and integrating the selected model into an interactive web application.

The final system uses the selected Random Forest Regressor to estimate food delivery time from user-provided delivery information.
